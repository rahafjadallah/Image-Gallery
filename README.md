# 🖼️ Interactive Image Gallery
An interactive and responsive image gallery built using HTML, CSS, and JavaScript. Users can explore photos, filter images by category, search for specific photos, manage favorites, and view images in a lightbox.

## ✨ Features
- **Category Filtering:** Filter images by category.
- **Search Functionality:** Search for images by title.
- **Favorites System:** Add or remove images from favorites.
- **Local Storage:** Save favorite images and remember the last selected filter.
- **Clear Favorites:** Remove all favorite images with confirmation.
- **Lightbox Viewer:** View images in a larger display.
- **Image Navigation:** Navigate between images using next and previous buttons.
- **Keyboard Controls:** Use arrow keys to navigate and Escape to close the lightbox.
- **Touch Navigation:** Swipe left or right to navigate on mobile devices.
- **Toast Notifications:** Display feedback messages when managing favorites.
- **Empty State:** Show helpful messages when no images match the search or filter.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Local Storage
- Array Methods (filter, includes, push)
- Event Listeners
- Keyboard and Touch Events
